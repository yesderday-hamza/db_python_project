    -for get_next_available :

    - for is_gateway :

        -ip as in the arg of the function is a dictionnary derived from the table in data base
    -for unreserved_ip :
        -it changes the status of an address from reserved to available(except for address of the gateway)

    -for allocate_ip :
        -it changes the status on an address from available to allocated
            + it creates a row in the devices table (at the same time)
